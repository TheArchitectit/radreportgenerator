# Delta for Research Agent

## ADDED Requirements

### Requirement: Honest provider labeling
When insights are generated by a mock provider, the UI MUST label them as demo/simulated.

#### Scenario: Mock run
- GIVEN the mock research agent
- WHEN analysis completes
- THEN UI indicates insights are simulated

### Requirement: Provider seam
The application MUST allow swapping mock analysis for an external LLM provider without rewriting the ViewModel.

#### Scenario: Provider interface
- GIVEN a future external provider
- WHEN registered in DI/config
- THEN the same analysis command uses it
